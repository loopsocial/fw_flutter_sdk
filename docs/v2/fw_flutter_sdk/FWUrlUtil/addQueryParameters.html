  1. required String url,
  2. required Map<String, String> parameters,
  3. bool encode = true,
})

Add multiple query parameters to url

Parameters:

  • url: The url to add query parameters. The url cannot be empty.
  • parameters: The key-value pairs of query parameters to add. Entries with an empty key are skipped.
  • encode: Whether to percent-encode each key and value. Defaults to true.
    • When true, pass raw (unencoded) keys and values; this function encodes them once via Uri.encodeComponent. Do NOT pass already-encoded values in this mode, otherwise they will be double-encoded (e.g. a value %20 becomes %2520).
    • When false, the keys and values are appended as-is without encoding. Use this only when they are already encoded, or are known to contain no characters that require encoding (e.g. a UUID or hex string).

Example:

const url = "https://firework.com";
final parameters = {"product_id": "1234", "sku": "5678"};
final updatedUrl = FWUrlUtil.addQueryParameters(
  url: url,
  parameters: parameters,
);
print(updatedUrl); // https://firework.com?product_id=1234&sku=5678

Implementation

static String addQueryParameters({
  required String url,
  required Map<String, String> parameters,
  bool encode = true,
}) {
  if (url.isEmpty || parameters.isEmpty) {
    return url;
  }

  var updatedUrl = url;
  parameters.forEach((key, value) {
    updatedUrl = addQueryParameter(
      url: updatedUrl,
      key: key,
      value: value,
      encode: encode,
    );
  });

  return updatedUrl;
}
